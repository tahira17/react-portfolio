# React Frontend Developer Portfolio

My personal developer portfolio built with React to showcase my frontend projects, technical skills, and experience.

**Live Demo:** [View Live](https://react-fe-portfolio.vercel.app/)

## Features
- **Responsive Single-Page Layout:** Smooth navigation across Home, About, Skills, Work, and Contact sections.
- **Project Showcase:** Direct links to live deployments and source code repositories.
- **Mobile-First Design:** Fully responsive across desktop, tablet, and mobile viewports.

## Tech Stack
- React
- Tailwind CSS
- Deployed on Vercel
